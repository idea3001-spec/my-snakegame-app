# 🐍 스네이크 게임

HTML5 Canvas로 구현한 클래식 스네이크 게임입니다.

## 실행 방법

`index.html` 파일을 브라우저에서 열면 바로 실행됩니다. 별도의 빌드나 서버 설치 과정이 필요 없습니다.

## 파일 구조

```
snakegame/
├── index.html   # 마크업 및 UI 구조
├── style.css    # 스타일 및 반응형 레이아웃
└── main.js      # 게임 로직
```

## 조작 방법

- **데스크톱**: 방향키(↑ ↓ ← →)로 뱀을 조종합니다.
- **모바일**: 화면을 스와이프하거나, 화면에 나타나는 방향 버튼(D-패드)을 사용합니다.

## 게임 규칙

- 400x400 캔버스, 20x20 격자 위에서 진행됩니다.
- 먹이를 먹으면 뱀이 한 칸 길어지고 점수가 +10점 됩니다.
- 벽이나 자기 몸에 부딪히면 게임이 종료됩니다.
- 50점을 획득할 때마다 레벨이 오르고 이동 속도가 10ms씩 빨라집니다(최소 30ms).

## 기능

- **난이도 선택**: 쉬움(200ms) / 보통(150ms, 기본값) / 어려움(100ms) / 매우 어려움(50ms) 중 선택할 수 있으며, 게임 오버 후 다시 시작할 때도 난이도를 바꿀 수 있습니다.
- **일시정지**: 게임 중 버튼을 눌러 언제든 일시정지 및 재개가 가능합니다.
- **레벨 시스템**: 점수에 따라 레벨이 오르고 게임 속도가 점점 빨라집니다.
- **최고 점수 저장**: `localStorage`를 이용해 브라우저에 최고 점수를 저장합니다.
- **TOP 5 순위표**: 지금까지 플레이한 게임 기록 중 상위 5개 점수를 화면 오른쪽 패널에 표시합니다.
- **반응형/모바일 지원**: 화면 크기에 맞춰 레이아웃과 캔버스 크기가 조정되며, 터치 기기에서는 스와이프와 D-패드로 조작할 수 있습니다.

## 저장되는 데이터 (localStorage)

| 키 | 설명 |
| --- | --- |
| `snakeHighScore` | 지금까지의 최고 점수 |
| `snakeHistory` | 게임 기록 목록(점수, 시각) — TOP 5 순위표에 사용 |
